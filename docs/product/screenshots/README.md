# Araf documentation screenshots

These SVGs are **documentation renderings**, not live-environment captures.

They exist to show the intended and currently implemented Araf information architecture in a form that renders reliably in GitHub documentation. The shell/navigation/page structure is grounded in current source, while names, counts, timestamps, IDs, alerts, and other example values are intentionally illustrative.

- `login.svg` — design-reference entry experience; actual authentication is BFF + OIDC/Keystone federation.
- `tenant-home.svg` — current Tenant Home structure and navigation.
- `users-access.svg` — current Users & Access table structure.
- `operator-overview.svg` — current Operator Platform Overview structure.

Do not use these files as evidence that a particular cloud currently has the sample resources, status, counts, or telemetry shown in them. Runtime/release claims remain governed by the repository's production evidence documents and acceptance gates.
