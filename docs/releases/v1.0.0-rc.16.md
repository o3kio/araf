# Araf v1.0.0-rc.16

**Integration release candidate for O3K PP.4.**

This candidate supersedes `v1.0.0-rc.15` for O3K PP.4 integration because
schema-defined JSON array fields in the native browser resource-create form
were previously submitted as strings. The form now uses the JSON Schema field
type to parse array text into a real JavaScript array before validation and
submission, while malformed and non-array input fails locally without a
mutation request.

- Release type: prerelease / integration candidate.
- Real O3K PP.4 acceptance: pending.
- Not GA and not final production certification.
- No multi-node HA claim; Araf #106 remains separate.
- `v1.0.0-rc.15` remains immutable historical evidence and was not modified.
- The generated GitHub Release body and release manifest bind this candidate
  to its exact source SHA and OCI digests.
- Required O3K API contract: `o3k-native-iam-v1`.
- Production release configuration has `fixture_mode_allowed: false`.

Use the published release manifest, digest list, SBOMs, provenance, and
verification guide from the GitHub Release. Deploy by OCI digest only.
