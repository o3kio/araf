# Araf v1.0.0-rc.14 release notes

Araf v1.0.0-rc.14 is an integration release candidate for the O3K PP.4
browser campaign. It contains the browser-native CSRF path, explicit JSON
Schema 2020-12 support, build-bound release identity, digest-pinned Compose
packaging, and the release compatibility manifest generated from the
published OCI artifacts.

This is not final O3K PP.4 acceptance, production certification, GA, or a
multi-node HA claim. Real O3K PP.4 acceptance remains pending a compatible
O3K deployment and the cross-product browser campaign.

## Source

- Tag: `v1.0.0-rc.14`
- Source SHA: `92d39d6e00e4a78ed5956c0d2968d2b7dbadec05`

## Artifact authority

The GitHub Release assets and the OCI image digests are generated only after
this exact tag is built. Deployments must use the published digest-pinned
references and the machine-readable release manifest; version tags are
convenience aliases only.

The release contains the canonical `araf-bff` multi-binary image for both
BFF surfaces, plus the tenant-console and operator-console images. The
manifest records the exact image, index/platform/config digests, source SHA,
backend modes, contracts, and `fixture_mode_allowed: false`.

## Verification

Download the release assets, verify the checksum manifests, validate the
release manifest against `release/manifest.schema.json`, and follow the
`VERIFY.md` instructions in the deployment bundle before starting Compose.
The supported reference runtime is Docker Engine 29.8.0 with Docker Compose
v5.5.1. The deployment consumes published images or their accompanying OCI
tarballs and never builds Araf source on the target.

## Compatibility

- Required O3K API contract: `o3k-native-iam-v1`.
- Supported backend profiles remain O3K and OpenStack where already
  implemented and evidenced.
- Fixture mode is disabled for this release artifact.
- External OIDC provider configuration, TLS trust, DNS, and deployment-owned
  secrets remain outside the release bundle.
