# P4.1 — Production observability

## Goal
Make Araf diagnosable as an industrial control-plane client without exposing secrets or requiring shell access.

## Implement
- structured logs with request/session-safe correlation IDs;
- metrics for BFF request volume/latency/errors, backend calls, auth/session failures, rate limiting and compatibility-operation reconciliation;
- distributed tracing/OpenTelemetry where appropriate across ingress/BFF/backend calls;
- health/readiness endpoints with meaningful dependency semantics;
- redaction tests for tokens, cookies, credentials and sensitive upstream payloads;
- Operator/support documentation for correlation from browser error -> BFF -> O3K/OpenStack request;
- bounded telemetry cardinality.

## Acceptance
A representative failed tenant operation can be diagnosed from supported telemetry and correlation without reading secrets or entering the data plane.
