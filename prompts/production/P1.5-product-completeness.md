# P1.5 — Product UX completeness and production-visible surface closure

## Goal
Ensure every production-visible route looks and behaves like an intentional cloud product, not a development scaffold.

## Implement
- inventory Tenant and Operator navigation/routes;
- remove, hide or explicitly capability-disable placeholder routes in production;
- standardize loading, empty, forbidden, not-found, degraded and structured-error states through Araf UI primitives;
- make navigation service/capability-aware without hard-coding backend type;
- finish responsive and density behavior for critical shell/resource flows;
- ensure Home/overview surfaces display only authoritative data; no fake counts/cost/health;
- add browser tests for production navigation and error/empty states;
- update screen inventory/docs to reflect actually supported production surfaces.

## Acceptance
There is no production menu item that ends at `implemented later`, fixture-only data or dead functionality. Unsupported capabilities are absent or clearly unavailable.
