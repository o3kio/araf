# P4.4 — Production security and software-supply-chain release gate

## Goal
Turn the existing threat model into enforceable release evidence.

## Implement/gate
- update threat model for O3K + OpenStack backend modes;
- dependency vulnerability scanning for Rust/JS;
- license policy checks;
- secret scanning;
- SBOM generation for release artifacts;
- provenance/signing policy for OCI/release artifacts;
- CSP/CSRF/session/XSS regression tests;
- malicious descriptor/schema/resource-label tests;
- tenant/operator/cross-project negative authorization tests;
- container/runtime least-privilege review;
- DAST or equivalent black-box security checks where practical;
- document manual penetration-test checklist and unresolved findings.

## Acceptance
No unresolved BLOCKER/HIGH finding for advertised production surfaces. Release artifacts have reproducible dependency inventory and the security gates run in CI/release workflow.
