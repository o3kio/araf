# P2.8 — Native O3K production convergence gate

## Goal
Prove Araf works as a real O3K cloud console with no production fixture dependency.

## Environment
Deploy real O3K + real supported providers + real IdP + Tenant Console/BFF + Operator Console/BFF using production configuration.

## Required journeys
Tenant: login -> choose scope -> list/create supported network/VM -> follow canonical Operation -> inspect resource/relationships -> stop/start/delete -> quota/usage/audit -> logout.

Failure: trigger a real control-plane/provider failure -> canonical Operation fails -> Araf exposes structured reason/correlation without fake success.

Isolation: Project A attempts Project B resource/Operation -> server-side denial/non-disclosure.

Operator: login -> inspect region/provider/service degradation -> correlate affected resources/Operations without data-plane shell.

## Gate
Audit production configuration for any fixture adapter, fake identity/scope, placeholder or hidden `501` path. None may be silently active.

## Evidence
Create `docs/engineering/o3k-production-evidence.md` with exact versions, topology, commands, tests, gaps and GO/NO-GO.

## Acceptance
Exactly one verdict: `GO — O3K PRODUCTION CONVERGED` or `NO-GO`.
