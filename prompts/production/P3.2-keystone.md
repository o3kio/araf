# P3.2 — Keystone identity, project and service-catalog adapter

## Goal
Provide a secure OpenStack identity/scope foundation behind the Araf BFF.

## Implement
- Keystone v3 authentication using supported configured auth modes;
- project/domain/region/service-catalog discovery required by Araf;
- keep Keystone tokens and credentials server-side;
- map authenticated context into backend-neutral Araf identity/scope projections;
- capability-detect services/endpoints rather than assuming presence;
- support federated/OIDC-backed Keystone where practical; legacy password mode, if implemented, must be explicit and never persist raw credentials;
- negative tests for project manipulation, expired token, wrong audience/scope and Tenant/Operator separation.

## Acceptance
A real supported OpenStack cloud can authenticate a tenant, enumerate authorized projects/regions and establish a secure BFF session without exposing Keystone tokens to browser JavaScript.
