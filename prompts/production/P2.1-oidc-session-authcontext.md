# P2.1 — Real O3K OIDC, BFF session and AuthContext convergence

## Goal
Replace fixture identity with the real production human-authentication path while preserving separate Tenant and Operator trust surfaces.

## Before coding
Inspect current O3K identity/token/AuthContext contracts and the upstream gap list. If the required O3K contract is missing, fix/coordinate upstream rather than inventing Araf IAM semantics.

## Implement
- real OIDC authorization-code flow through confidential BFF clients;
- distinct Tenant and Operator OIDC/session configuration;
- secure server-side token handling and session lifecycle;
- current-user/AuthContext projection derived from O3K;
- logout, expiry, rotation/refresh behavior according to the accepted contract;
- no access/refresh token in browser-readable storage;
- negative tests: tenant session to operator route, expired session, invalid state/nonce, CSRF, manipulated scope.

## Acceptance
Production mode authenticates a real user and obtains authoritative O3K context without fixtures. Browser inspection cannot recover reusable O3K credentials.
