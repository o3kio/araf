# P4.2 — Performance, scale and resource budgets

## Goal
Prove Araf remains bounded and responsive on cloud-scale inventories and concurrent use.

## Implement/test
- large synthetic and database-backed resource populations;
- bounded pagination/filter/sort through BFF and backend adapters;
- BFF concurrency, connection pooling, timeout and memory behavior;
- browser bundle/loading/render budgets for large tables;
- cache policy and invalidation that cannot cross scopes;
- backpressure/rate-limit behavior;
- load tests for representative list/show/action/operation flows;
- measure O3K and OpenStack backend profiles separately and document upstream limits rather than hiding them.

## Acceptance
Publish `docs/engineering/performance-evidence.md` with test topology, percentile latency, throughput, memory/CPU, browser budgets, failure thresholds and known bottlenecks. No production path requires materializing unbounded inventories.
