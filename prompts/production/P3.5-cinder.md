# P3.5 — Cinder Block Storage adapter

## Goal
Provide production block-storage support through the same Araf resource runtime.

## Implement
- Cinder v3 volume list/show/create/delete as required by supported profile;
- volume type/size/AZ discovery where user-selectable;
- attachment-related reads and supported actions needed by Araf VM/storage journeys;
- status/error normalization preserving authoritative Cinder state;
- quota integration hooks for P3.8;
- CompatibilityOperation correlation for async lifecycle changes;
- cross-project/unauthorized negative tests.

## Acceptance
Araf volume flows work against real Cinder with no Cinder-specific React resource framework and no fake completion state.
