# P1.2 — Browser E2E and visual shell regression CI

## Goal
Make real browser behavior a required merge signal so semantic/unit green builds cannot regress into an unstyled or unusable console.

## Implement
- run the existing Playwright suite in GitHub Actions on PRs;
- pin/install Chromium deterministically and cache only safe reusable layers;
- add Tenant and Operator shell smoke coverage at representative desktop and narrow viewports;
- verify navigation active state, scope controls, search, focus/keyboard traversal and non-default shell layout;
- prove omitting the shell stylesheet causes a deterministic failure;
- retain trace/screenshot artifacts on failure;
- keep first-pass assertions semantic/computed-style based rather than broad brittle pixel diffs.

## Preserve
No trust-boundary, backend, fixture-production, resource-runtime or O3K semantic changes.

## Acceptance
`pnpm e2e` is executed by CI, existing E2E remains green, the known raw-shell regression is caught, and failures are diagnosable from artifacts.
