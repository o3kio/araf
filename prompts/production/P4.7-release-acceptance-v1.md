# P4.7 — Release candidate, pilot/soak and v1.0 decision

## Goal
Make the final production decision from evidence, not roadmap completion.

## Preconditions
P1-P4.6 complete. P2.8 must be GO. P3.9 must be GO if OpenStack will be advertised as production-supported in this release.

## Acceptance matrix
- clean install using release artifacts;
- production OIDC/HTTPS/session flow;
- complete supported Tenant and Operator O3K journeys;
- supported OpenStack journeys when advertised;
- real success and failure Operations;
- isolation/security negative tests;
- multi-replica restart/failure tests;
- scale/load thresholds;
- observability/correlation;
- upgrade and rollback;
- documentation/support handoff.

## Pilot/soak
Run a representative production-like pilot/soak long enough to exercise authentication renewal, repeated operations, restarts, monitoring and backend transient failures. Record duration, workload, incidents and fixes; do not use an arbitrary elapsed time as a substitute for workload coverage.

## Evidence
Create `docs/engineering/production-release-evidence.md` with release SHA/version, environments, exact supported profiles, all gate results, outstanding deviations and findings.

## Final verdict
Exactly one:
- `GO — PRODUCTION READY`
- `GO WITH BOUNDED DEVIATIONS`
- `NO-GO — NOT PRODUCTION READY`

Never issue GO with unresolved auth/isolation/resource-truth blockers or unresolved HIGH/BLOCKER findings.
