# P3.3 — Nova Compute and Glance Image adapter

## Goal
Map the Araf Virtual Machine journey to a real OpenStack cloud while preserving the generic resource UX.

## Implement
- Nova server list/show/create/delete/start/stop for the supported profile;
- Glance image list/show/select required by create flow;
- flavor/compute-size discovery using the authoritative OpenStack APIs for the deployed profile;
- keypair and availability-zone inputs only where required/supported;
- bounded pagination/filtering where upstream supports it; document bounded compromises explicitly;
- normalize status/spec into Araf resource descriptors without losing important failure diagnostics;
- mutations return CompatibilityOperation correlation, never instant success.

## Tests
Use contract fixtures plus real OpenStack integration tests. Include unauthorized project access and async failure paths.

## Acceptance
The same generic Araf server list/detail/create/lifecycle components work against OpenStack with no Nova/Glance-specific React page.
