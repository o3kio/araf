# P2.2 — Real scope, service, resource and schema discovery

## Authority
O3K northbound convergence #907 is merged and complete at
`21fe687c387a04f107b6e87fac04060b1c28e449`. P12-IAM scope discovery, region/AZ
discovery, service/resource/action discovery, versioned schemas, and bounded
native resource contracts are frozen public contracts. Araf is a consumer of
those contracts; it must not design replacement O3K APIs or add cloud shadow
semantics.

## Goal
Remove static project/region/service descriptor assumptions from production
composition while preserving the existing authoritative P12-IAM scope path.

## Implement
Using current authoritative O3K contracts:
- discover effective project/scope and switchable authorized scopes;
- discover region/AZ/global semantics where supported;
- consume real service catalog / ServiceManifest public projections;
- consume real resource-type descriptors and versioned schema references;
- validate descriptors/schemas before exposing them to the generic runtime;
- cache only with safe scope/version invalidation (correctness is preferred when
  no cache is necessary);
- capability-hide unavailable services;
- reject malformed/malicious descriptor/schema input safely.

Fixture/static descriptors remain development and test tools only and must
never silently substitute for missing production O3K discovery. Production
upstream, authentication, contract, and partial-discovery failures must remain
distinct structured states; an empty valid inventory is not an upstream
failure.

## Preserve
Araf owns visual presentation; do not push table/widget-specific UI metadata into O3K unless an accepted generic contract/ADR already exists.

## Acceptance
Production navigation and generic resource registration are derived from real
O3K discovery with no committed fixture descriptors required for supported
services. Every advertised lifecycle/action capability maps to a public O3K
route; unavailable capabilities are not rendered. Tenant/operator scope and
credential custody remain server-side, and unknown or malformed schema data is
treated as bounded data rather than executable content.

This workstream is discovery only. Full Compute/Network/Volume/Image lifecycle
convergence, Operations Center, governance, diagnostics, and metering remain
outside P2.2 (#46–#50).
